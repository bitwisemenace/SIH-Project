# Delhi NCR Air Quality Forecasting System

## 📌 Project Overview
A high-resolution, coupled weather-chemistry forecasting system
designed to predict AQI in Delhi NCR for the next 72 hours.

## 🎯 Objective
To improve AQI forecasting by modeling the interaction between
meteorological conditions and pollutants such as PM2.5, PM10, O3 and NOx.
